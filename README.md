I work on machine translation for low-resource languages. At the Universidad de Buenos Aires I helped build QomL'aqtaqa, the first computationally usable Qom–Spanish parallel corpus, and fine-tuned NLLB-200 baselines on it. What I care about most is evaluation that tells the truth: split design, ablations, and catching a headline score that's inflated.
